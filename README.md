# Cherisha KG — Portfolio

Personal portfolio for Cherisha Killari Giribabu, focused on software engineering and data analysis.

## Pages

- Minimal professional homepage
- Project index and detailed project pages
- Experience index and detailed role pages
- About page with education, interests, and contact links

## Stack

- Next.js
- React
- TypeScript
- CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
